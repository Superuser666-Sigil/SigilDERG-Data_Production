# Runbooks

This directory contains operational runbooks for common pipeline operations and incident response.

## Index

| Runbook | Description |
|---------|-------------|
| [Pipeline Execution](pipeline-execution.md) | Running the full pipeline |
| [Troubleshooting](troubleshooting.md) | Common issues and solutions |
| [Incident Response](incident-response.md) | Handling failures and outages |
| [Scaling](scaling.md) | Scaling the pipeline for larger workloads |

## When to Use Runbooks

- **Before** running large-scale pipeline executions
- **During** incident investigation and resolution
- **After** for post-mortem documentation

## Contributing

To add a new runbook:

1. Copy the template structure from an existing runbook
2. Include: Overview, Prerequisites, Steps, Verification, Rollback
3. Add to the index above
4. Submit a PR for review
